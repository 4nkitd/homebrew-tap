# Homebrew Tap (`4nkitd/tap`)

Official Homebrew tap for Ankit Yadav's tools and macOS applications.

## 🚀 Installation

Add this tap to your Homebrew installation:

```bash
brew tap 4nkitd/tap
```

---

## 📦 Available Formulae & Casks

### CLI Tools (`Formula`)

| Tool | Installation | Description |
| :--- | :--- | :--- |
| **koko** | `brew install 4nkitd/tap/koko` | High-Performance Standalone Text-To-Speech CLI for macOS (Zero Python) |
| **headroom** | `brew install 4nkitd/tap/headroom` | macOS Menu Bar AI Subscription Usage Tracker |
| **rustdesk-cli** | `brew install 4nkitd/tap/rustdesk-cli` | Headless RustDesk client CLI |

### macOS Apps (`Cask`)

| App | Installation | Description |
| :--- | :--- | :--- |
| **openbar** | `brew install --cask 4nkitd/tap/openbar` | Native AI coding quotas with multiple accounts; successor to Headroom |
| **mordo** | `brew install --cask 4nkitd/tap/mordo` | Soundboard app for macOS (Rust + GPUI) |
| **mp-1** | `brew install --cask 4nkitd/tap/mp-1` | Field-audio mini player for macOS |
| **ocean** | `brew install --cask 4nkitd/tap/ocean` | Mobile-first web client for opencode |
